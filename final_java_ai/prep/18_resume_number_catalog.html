Resume Number Catalog (every PDF metric)

How to use this page

  • This is the one-screen list of every number on Tarun_Mittal_SSE_5yr_Java_AI.pdf, with one plain sentence saying what each number means.
  • Read it five minutes before a call. If a number needs a longer explanation, follow the link to Metrics Derivations, which has the arithmetic and the "say it / do not say it" lines.
  • Memorise the warning box and the off-PDF table. Those are where candidates usually slip.

Tags in one line each. MEASURED means there is a log, benchmark, config or doc. STATED means it is printed on the PDF from the project source, with no extra arithmetic in prep. ESTIMATED means arithmetic I can show. HISTORICAL means from my past work records. TARGET means a design goal.

Other sources: GROUND_TRUTH, IA bullet defense, IA interview pack, FRM deep dive, Menu deep dive, Masters and GFG deep dive.

Numbers people mix up. 348k article-seasons were scored. 1.6M is the catalog (off PDF). The 80% gate and the 300 cases are one benchmark. The 73% cost cut, 100% coverage and 74% baseline are a different 200-case benchmark. 15.5× is query time. 170 GB is load time. 344k is rows per second, not requests per second. The 4.09B copy was measured while running, not finished. "Led 3" is Uber FRM. "Mentored 2" is Masters India.

Impact Analytics, AssortSmart (on the PDF)

AssortSmart helps retailers decide which products to keep, drop or add each season. An article-season is one product in one season.

Uber via EPAM, FRM Scoping Platform

FRM scoping decides each quarter which financial line items and entities are material enough to need audit testing. It replaced Google Sheets.
