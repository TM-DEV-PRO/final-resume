How to use this page

  • It lists every line on Tarun_Mittal_SSE_5yr_Java_AI.pdf, says in one plain sentence what that line means, and points to the doc that defends it in depth.
  • Use it as the table of contents for interview prep. When a recruiter quotes a bullet back to you, find the row here and open the linked pack.
  • Memorise the "Tag" column. It tells you how carefully to phrase each claim.

Tags. MEASURED means there is a log, benchmark, config or doc. STATED means it is printed on the PDF from the project source, with no extra arithmetic in prep. HISTORICAL means from my past work records. TARGET means a design goal. DESIGN means a written design that is not a resume outcome. Full number arithmetic is in Metrics Derivations and the short list is in the Number Catalog.

Canonical claims: ASSORTSMART_TAB_RESUME. Keep/Drop pipeline reference: track copy and shared copy.

Impact Analytics: AssortSmart, Senior Software Engineer (Platform and AI)

AssortSmart is a retail merchandise planning product. Planners use it to decide which products to keep, drop or add each season. IA platform APIs are Go/Gin. The agent plane is Python (FastAPI, LangGraph).
