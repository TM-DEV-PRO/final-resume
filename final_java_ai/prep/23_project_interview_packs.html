Project Interview Packs (canonical)

How to use this page

  • This is the front door to the per-project interview packs. Each pack plays a tough interviewer against you, project by project.
  • Read this page first to pick the right pack for the role, then open the pack.
  • Memorise the one-line pitch and the "current PDF bullets" for each project below. They are the version to trust if a pack's older headings disagree.

Every project on the current PDF (Tarun_Mittal_SSE_5yr_Java_AI.pdf, Java + Python track) has a pack. A pack is a coaching file with a 30-second and 2-minute explanation, an architecture sketch, the design decisions, a bullet-by-bullet defence, a mock interview, and a "do not say" list. The packs were first generated in July 2026 by pairing an interviewer agent with a candidate agent for each project, and they have been partly re-synced since.

Tags used here. MEASURED means there is a log, document or code behind the number. ESTIMATED means arithmetic I can show. HISTORICAL means from my past work records. TARGET means a design goal, so say "targeting".

The two questions every pack will throw at you

"What exactly did you own versus the team?" Start with the direct answer: name the bullets you owned. Then name what you did not own. At Uber FRM, the HFM extract pipeline was shared and the real-time collaboration and Slack notification service was built by others. At Impact Analytics, the Postgres-to-ClickHouse CDC pipeline was a colleague's work. Saying what you did not own makes everything else you say more believable.

"How do you know that number is real?" Give the measurement source in one sentence, then the arithmetic. For example: "The 15.5x is 189 seconds divided by about 12.3 seconds on a 250-million-row benchmark harness." Or: "The $600K is about $2 per menu times 30K menus times 12 months, which is $720K, and I round down to $600K to be conservative." The full derivations live in 09_metrics_derivations.md and 18_resume_number_catalog.md.

Stack note for this track

On this track (summary: Java and Python, with Go at Impact Analytics), Uber FRM is Java and Spring Boot with Spring Data JPA and Hibernate on MySQL, and Masters India is Spring Boot microservices with Hibernate. Impact Analytics platform APIs are Go/Gin, the IA agent plane is Python (FastAPI, LangGraph), Uber Menu is Python, and GeeksforGeeks is Django. Always say Spring Boot and Spring Data JPA / Hibernate for FRM, and Spring Boot for Masters India.
