# Rubrik · Databricks · PlanetScale — how to pitch (honest)

## Rubrik
- Pitch: distributed systems ownership, reliability, cloud backends (Java or Go), Kafka-scale ingest experience.
- Proof: Masters Kafka 1M+/day, Uber Menu pipeline, FRM design ownership, on-call discipline (Masters).
- Do not claim backup/security product experience you do not have.

## Databricks
- Pitch: analytical stores (ClickHouse, BigQuery), streaming (Kafka, Flink), Python data/AI agents.
- Proof: 250M pivot POC Postgres→ClickHouse; Menu Flink; AssortSmart agent tools on CH.
- **Do not claim Apache Spark** on this PDF. If asked about Spark: adjacent Flink/Kafka experience + willingness to ramp; do not invent production Spark ownership.

## PlanetScale
- Pitch: MySQL/Postgres reliability, sharding, high-throughput APIs, Go or Java backends.
- Proof: Masters tax-quarter sharding + Kafka IRP; FRM MySQL schema; distributed systems core.
- **Do not claim Vitess** or PlanetScale employment. Sell database reliability and sharding patterns you actually ran.
